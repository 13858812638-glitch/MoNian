# 桌面侧栏目录切换与折叠优化候选 · 2026-10-21

用户反馈上一候选切换文件夹、展开和折叠仍卡顿，并要求精简筛选列表右侧的“…”；本轮继续在 `fix/desktop-sidebar` 开发，未晋升正式冻结基线。

## 改动

- 文件夹选择先读取左栏滚动位置，再提交右侧结果。原来提交结果后才读取，会迫使浏览器立即布局。临时快照只供本次微任务内的导航刷新使用，带结果代校验并自动过期；显式会话恢复优先，原有滚动锚点、实时会话捕获和卸载清理保留。
- 折叠子目录时先移除失效行，再整理剩余行顺序。后面的兄弟目录无需重新移动；键盘排序、分割线和“显示全部”仍按原顺序规则工作。
- 排序复用一个 `Intl.Collator("zh-Hans-CN", { numeric: true })`，与原逐次 `localeCompare` 使用相同语言及选项。中文、数字、大小写、重音、相同键的稳定顺序及用户自定义排序均有等价测试。
- 去掉桌面侧栏文件夹、标签、属性分组标题右侧的“…”按钮，计数恢复与普通行对齐。右键分组标题 →“选择和管理…”打开原 Picker；排序模式仍为拖动柄留出空间。

这次精简的是左侧导航的分组按钮。右侧文件结果的操作菜单保留。移动侧栏的布局与触控交互、其他宿主的弹窗定位没有改动；共享排序工具只减少比较器创建，排序含义保持一致。
