# 桌面侧栏弹窗与顶部命令栏候选

用户反馈：侧栏的重命名对话框出现在远处的编辑区；左侧缺少移动端导航底栏中的命令按钮。本候选继承此前的侧栏性能、拖动调宽、搜索条右置改进。

## 改动与范围

所有新增定位都检查所属 `SearchCore.hostKind === "sidebar"` 且非移动端，不根据当前活动窗口或全局主题推断宿主。

- 共享 DialogSession 的重命名、创建、删除确认及调色对话框，改为相对于侧栏可见区域水平居中，竖向保留原位置比例。宽高受侧栏及视口边界约束；遮罩也限于侧栏。继续使用原来的 portal、输入框、提交、取消及焦点流程。
- 普通 Picker 原本已经按工作区边界定位，因此保留它的锚点算法。补充侧栏内部滚动和尺寸变化监听；嵌套 Picker 的继承尺寸在侧栏缩小时重新约束，避免越界。侧栏收起时隐藏所属浮层，重开后恢复当前内容。
- 定位更新按 requestAnimationFrame 合并；只在弹窗存续期间监听，并在关闭/销毁时清理。无轮询、额外淡入动画或重新聚焦补丁。
- 左侧标题下方展示现有导航命令栏，沿用移动端“筛选导航”配置的顺序、显隐及自定义图标。默认可见：折叠/展开、查看结果、视图设置、历史、创建。长命令栏自动换行。
- 移动已有按钮到顶部命令栏，保留同一个动作 Owner；未配置在顶部的排序/批量等原有动作仍留在原位置。桌面点击“折叠全部”或打开侧栏工具不清除搜索词；移动端原有返回筛选流程保持不变。

普通标签页、主搜索模态窗口、嵌入窗口、移动端未启用上述桌面侧栏定位或顶部命令栏。Obsidian 原生鼠标菜单和全局文件命令浮层保留各自宿主，不因侧栏处于活动状态而改动。

## 检查覆盖

`scripts/sidebar_popup_audit.py` 使用真实插件代码和 Chromium 受控 Obsidian 宿主，覆盖浅色、深色，以及 sidebar / tab / window / embedded / mobile 五种配置。

- 对话框：文件夹重命名、创建文件夹、删除确认、调色、文件重命名。
- Picker：文件夹、标签、属性、排序、视图、历史、移动文件、图标选择；包括真实图标子 Picker 的继承尺寸及返回流程。
- 交互：顶部命令、搜索保留、宽度变化、输入内容及焦点保留、Escape、收起/重开侧栏、销毁清理。
- 隔离对照：将 tab / window / embedded / mobile 的上述弹窗坐标和尺寸与改动前保存的运行包逐项比较，浅/深色均保持一致。

初轮旧实现为 40 项通过、16 项失败；完成基本修复后增加收起侧栏用例，又复现了两个主题下 Picker 残留的问题，并已补充修复。最终结果存于 `reports/sidebar-popup-results.json`，旧实现证据存于 `reports/sidebar-popup-before.json`。

搜索条件验收的两处夹具随交互调整：桌面折叠现在明确要求保留搜索词，移动端仍要求返回时清空；桌面 Picker 使用可见的分组管理按钮作锚点，替代只用于移动端返回的隐藏按钮。原夹具在输入防抖更新时会让隐藏锚点被命令栏清理，从而产生超时；没有放宽输入可见性、选区、焦点或命中检查。保留首轮失败及桌面重跑结果。

其他检查：工程静态检查/构建通过；全量 Node 251/255，4 个原型/方法快照失败与上传代码一致；历史浏览器 A/B 仍在 4 个初始快照处不匹配。桌面导航 55/55、移动侧栏 96/96、索引重试 7/7、Chromium portal 48/48、光标检查 36/36 通过。搜索条件验收与最终专项数量见 `reports/sidebar-popup-validation.json`。

这些结果来自受控 Chromium，未在原生 Obsidian、iOS/Android 真机或 WebKit 上验证。浏览器不能完整证明用户电脑上的流畅度和第三方插件组合。

## 安装

使用 `downloads/GLS-Sidebar-Popups-Toolbar-20261021.zip`。关闭插件并备份旧文件，覆盖原 GLS 插件目录中的 `main.js`、`styles.css`；保留原 `manifest.json`、`data.json`，然后启用插件。本包仍是开发候选，未升级冻结基线。
