# GLS Navigator 整合归一 · 2026-10-22

唯一开发基线为当前会话上一份完整代码 `7fd3f53`。本次从该版本的 `src/` 完成重构、构建及验证，没有从原始上传包或历史冻结版本回填。运行包只含 `main.js`、`styles.css`，保留实际安装的 `manifest.json`、`data.json`。

本轮关闭上一轮明确记录的三项源码归一缺口，并重构结果节点提交。下面区分实际实现、已运行证据与运行环境限制，不以“完美”代替验收。完整静态文件清单见 `reports/current/full-source-style-audit.json`；当前交付以本报告为准，旧文档中的桌面专属策略属于历史记录。

## 同一功能只有一套运行实现

| 职责 | 唯一权威与正式路径 | 本轮处理 |
|---|---|---|
| 文件、索引与偏好 | LocalSearchPlugin → 原索引/写入服务 | 不复制业务索引或持久状态；沿用通知与销毁边界 |
| 查询与精筛 | SearchCore 的 QueryState、FilterState → FilterEngine / ResultRanker | 点击继续只提交一次；重复点击保留取消选中语义 |
| 导航目录与计数 | Navigator 消费同一导航候选 | 桌面/移动共用全局目录、当前文件夹计数；零计数项保留；索引、目录、配置变化统一失效 |
| 属性展开 | Navigator.expanded → 同一行投影 | 所有导航属性键原地展开；只为展开的键构建值统计；删除无生产调用的 `_propertyStats` |
| 导航 DOM | plannedRows → reconcileDomChildren | 删除旧逐行游标搬移分支；稳定行只更新计数/选择；折叠不驱动结果重搜 |
| 投影调度 | 一个 `_projectionTask` | 统一微任务提交；返回筛选页同步消费同一任务；销毁/消费后已排队回调通过身份检查退出；无伪定时器取消 |
| 普通浏览卡片 | Renderer 的有界 UI 缓存 → 正式区间遍历 → 同一提交 Primitive | 各宿主共用内容/配置校验、最多 96 张卡；取消占位节点与整页拆装；保留的节点持续连接；失败恢复原节点、位置、数组和高度状态 |
| 虚拟列表 | SparseHeightIndex + Renderer | 共用基于实际可见行数的缓冲预算；大跨度键盘移动与可见区域覆盖优先；挂载后注册高度观察 |
| 标签与视觉状态 | Hover Owner + setSearchAttribute / setDomText / setDomProperty | 删除 Navigator/Filter Rail 两份标签意图缓存；同值不写 DOM；可见文字更新保留隐藏辅助标签与图标 |
| 弹窗与提交 | SearchDropdownController / dialog-session / sidebar-popup | 侧栏定位只影响侧栏发起的窗口；父子栈、取消、Esc、提交锁与焦点 Guard 仍共用 |
| 键盘与焦点 | 原生 input + MobileViewportState + MobileFrame | 键盘只消费宿主真实信号；外框保持 Base Position；内部滚动区消费键盘高度 Token；表头/外部焦点释放旧滚动区，禁止修改其他窗口的滚动容器 |
| 桌面/移动适配 | 原 DOM、组件、状态机与生命周期 | 保留桌面分栏/命令栏位置、移动页面显示、真实鼠标/触摸输入差异；不保留平台专属数据算法 |

缓存只保存可失效的派生 UI/统计，不作为可编辑状态源。查询、外部选择、批量、动作展开、创建和弹窗占用等状态继续通过共享资格判断走正式构建器，防止复用旧事件或展开状态。

## 样式与组件归属

生产样式仍只有 `src/styles/styles.css`。新键盘上限 `--ui-mobile-keyboard-height: min(520px, 55vh)` 有实际内部滚动容器消费者；固定默认值不增加 Style Settings 覆盖链。既有 `--ui-mobile-modal-height:83.5dvh`、顶部安全区与临时锁框继续由共享样式负责。JS 新增的写入只表达实时交互或测量结果，没有写死新的颜色、尺寸、圆角等视觉参数。

扫描全部 153 个 JS 模块和生产 CSS，审查调用链、状态、事件/监听、清理、缓存失效、同步、焦点、键盘、手势、移动行为和同类组件。CSS 解析无错误；723 条规则、28 个设置 heading、143 个参数，无重复设置 ID、同名 Section 内根或缺失消费者候选。重复选择器经上下文区分；几何测量/树深/运行时显隐不被误删为静态样式。仓库没有用户实际 Vault 的 CSS Snippet；未新增片段接管或第二个视觉 Owner。

## 复现、验收与初轮失败

- 固定基线源码和 CSS 的归一专项：26 项中 8 项通过、18 项失败；整合实现 26/26。覆盖四种桌面/移动与 Sidebar/Tab 组合，包括无拆卸提交、完整失败回滚、同值属性零变更、内外焦点边界及外框高度。
- 原有导航、属性、卡片、筛选条、滚动、分栏、命令栏、弹窗、生命周期、搜索、焦点、Portal、光标与移动侧栏专项均执行；详细数量和最终状态见 `reports/consolidation-validation.json`。
- 最初键盘夹具缺少移动 viewport，测试结果不能代表真实尺寸；修正夹具后用固定基线重新跑出有效前后对照。混合文件的初次探索结果没有用于通过率或性能结论。
- 首轮回归发现部分测试仍要求已取消的“移动端新建卡片/桌面独立属性 Picker”，或读取旧 timer/游标字段。已按新统一合同修正这些精确断言，同时保留真实点击、DOM 身份、失败回滚、缓存上限、销毁验证；未保留废弃运行分支来迎合测试。
- `_propertyStats` 是无生产调用的内部方法，非公开插件接口；契约测试只显式准许这一项退休，并断言其确实不存在。所有无关描述符继续比较，历史冻结快照没有改写。
- Node 的四个历史冻结契约差异与浏览器四个初始历史快照差异仍如实保留；浏览器 A/B 在初始差异处退出，不能算作后续场景全过。当前行为由独立交互套件验收。

## 性能证据

Chromium 模拟宿主、4 倍 CPU 降速，按“基线 → 整合 → 整合 → 基线”顺序，每个规模每轮执行 50 次文件夹点击和 40 次展开/折叠。它测量同步选择调用，不等同于用户设备输入到绘制完成延迟。

| 规模 | 基线两轮选择均值 | 整合两轮选择均值 | 基线结果提交均值 | 整合结果提交均值 |
|---|---:|---:|---:|---:|
| 161 文件 | 20.47 ms | 18.36 ms | 12.70 ms | 10.29 ms |
| 2400 文件 | 21.96 ms | 19.17 ms | 11.41 ms | 9.29 ms |

选择同步耗时均值约降低 10%–13%，结果提交均值约降低 19%；P95 有波动，小规模没有稳定改善，因此不宣称尾部卡顿全部消失。结构性证据更明确：保留结果卡提交时拆卸次数为零，同值标签/状态重复同步八次的节点变更为零。逐轮分布和最终构建补验见 `reports/consolidation-benchmark.json`。

## 实际覆盖边界

本次交付是经过整合重构、可重复构建和模拟宿主回归的运行代码。当前环境没有原生 Obsidian、用户真实 Vault、iOS/Android 真机或 WebKit；原生性能、第三方插件组合与真实键盘/光标效果尚未实机验证。自动化不证明所有字体、内容、设置组合绝对等高，也不证明任何设备都不会掉帧。正式冻结仍遵循用户实机确认后的版本流程；此限制不意味着保留本轮已经找到的重复实现。

安装时关闭 Obsidian，解压运行包，用两份文件覆盖原插件目录中的同名文件，再启动 Obsidian。保留原有 manifest 和数据。下载链接与包内校验记录见 `reports/consolidation-delivery.json`。
