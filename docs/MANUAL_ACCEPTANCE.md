# 原生宿主与真实设备验收单

这些项目在本次执行环境中**尚未验证**。Chromium 的移动尺寸和合成事件不能替代 iOS/Android 的 WebView、输入法、手指滚动或 Obsidian 的原生窗口。

## 准备与安全范围

先复制整个测试仓库及原插件目录，保留原 manifest.json、data.json、GLS 元数据目录和模板。原版 A、模块版 B 使用两份相同的仓库副本，不能在同一个启用中的插件目录内来回覆盖并当作等价测试。不要在生产资料上验证删除/移动；准备可丢弃的 Markdown、Canvas、图片和绘图测试文件。

记录 Obsidian 版本、操作系统、设备、主题、社区插件列表、真实 manifest 的 ID/version/minAppVersion/isDesktopOnly，以及原版/模块版 main.js 校验值。缺 manifest 的本次附件无法独立完成此准备步骤。

## 加载、入口和生命周期

覆盖 B 的 main.js/styles.css，保留 B 副本的原清单和数据，重新加载插件。检查设置值未重置、没有新插件 ID 或第二个视图注册；8 个命令均可见，侧栏和标签页使用原 ViewType。分别打开 Modal、浮窗、侧栏、标签页和工作台嵌入入口，关闭后再次打开。连续加载/卸载至少 10 次，检查重复事件、后台报错、残留弹窗、重复菜单/图标及释放后的异步回调。

这一步用于确认真实宿主注册与释放；当前 mock 订阅计数为 0 不能替代真实环境的内存分析。

## 搜索、条件与创建上下文

对同一文件集分别输入中文、英文、空格和多段关键词；用真实中文输入法在候选尚未确认时切换或取消，检查不会抢先搜索/创建。输入搜索后改文件夹，再按橡皮擦；从筛选页返回后清当前条件。对比 A/B 的结果、选中、排序、焦点和滚动锚点，不用本次重构擅自修复原版已有产品行为。

制造未命中，核对创建继承当前条件和上下文；切换 Markdown、Canvas、Excalidraw、模板，确认只有原业务定义的变更。创建后是否回列表、原焦点与文件命名均与 A 一致。再次打开，验证设置和历史读回一致。

## 布局、Picker、Dialog 与输入法

桌面大/小窗口、移动横/竖屏、浅/深色模式各对照一次。检查标题、统计、工具栏、筛选池、当前条件、结果卡、空状态和底部操作栏的原 DOM/CSS 样式。测试属性多值/多层标签/多层目录、单选立即关闭、多选底部或完成按钮的原行为。

从结果卡侧滑、上下文菜单、命令和多选工具栏分别触发重命名/删除。用真实 iOS/Android 输入法检查光标、键盘遮挡、关闭后是否意外重新弹键盘、Tab/Esc 和返回焦点。打开子 Dialog 后点底层区域、切换窗口、提交失败、连续点确认，检查原互斥语义。

## 多选、拖拽、侧滑与原生滚动

桌面普通点击建立 Anchor，Shift 扩展/收缩同一范围，Ctrl/Command/Alt 的原组合行为保持；移动端不强制套用桌面 Shift 语义。全选、查看已选、退出批量、当前结果改变、外部删除/改名后的选择集合均与 A 一致。

真实鼠标/手指拖拽树同级排序、层级移动、取消、越界、自动滚动以及提交失败；确认最终顺序和持久化一致。测试卡片侧滑动作与整层右滑返回隔离；一级关闭、子级返回、纵向滚动和横向原生滚动不被抢占。Mac 触控板惯性尾段和快速连续手势另验，不用合成 PointerEvent 代替。

## 写入、时间与 NAS

对 Markdown 批量增加/删除标签和属性，核对 YAML 原类型、正文、前后空行、时间字段与错误提示；真实 YAML 中增加字符串、列表、布尔、数值、空值、Unicode 和已有复杂结构案例。当前测试宿主只使用 JSON/简单 YAML 子集，不证明所有 YAML 解析行为。

对 Canvas/图片写项目和属性，核对原文件内容没有被属性写入改掉，侧车格式和目录不变。两台设备/NAS 实测元数据分片先后到达、设备离线、同名文件、移动后远端旧快照、只读目录/断连、部分成功与恢复；对比创建/修改/正文修改/打开时间，不擅自改变原时间架构。

## 真实工作台与 Dida

在原安装 ID 下读取 externalSearchApiVersion，确认 18；枚举 externalSearchApi 键，与 PUBLIC_API.md 对照。真实工作台执行 open/mount、受限范围、选择回调、范围更新、captureSession、dismissTop、destroy；范围更新不得重建同一输入节点或新增权威文件索引。

开启原 Dida 插件，检查项目目录就绪通知、更新/退订、仅 Dida 项目、虚拟属性 provider 热替换和旧句柄释放。对所有仍在使用的动态插件公开方法做真实调用；不能因自动化测试未调用而删除。
