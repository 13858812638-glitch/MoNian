# GLS v5.2 桌面侧栏优化候选

> **后续布局调整：搜索条右置。** 按用户反馈，将桌面主搜索条及附带按钮移到右侧结果列表上方，左侧保留 GLS Navigator 标题和目录。仅在初始化时移动现有控件，窄窗和分栏切换不再搬动输入框；移动端保持原位置。新增位置、搜索结果、缩放后输入/焦点/选区保留和移动端位置检查，合并桌面专项共 **55/55 通过**。本轮重新执行搜索条件验收为 144/144 通过，静态检查和构建通过；Node 仍为 251/255，历史浏览器对照仍有 4 个初始快照差异。报告见 `reports/desktop-search-right-results.json`；下表保留上一轮侧栏优化的验证记录。

针对默认主题下切换文件夹、展开/折叠卡顿，以及折叠箭头显示和左面板无法调宽的问题，从上传的 Navigator 候选继续开发。当前分支为 `fix/desktop-sidebar`，不是正式冻结版本。

## 行为与原因

- 桌面已完成投影的分组直接切换显隐，保留现有行；原先会重新投影，并在列表顶部仍逐行测量位置。
- 文件夹选择复用物理目录计数与目录行，只更新选中状态。文件创建、删除、重命名、索引及偏好变化会使缓存失效；标签/属性仍遵循原来的范围投影。
- 结果位于顶部时，越界判断直接返回，避免插入结果卡片期间强制读取滚动高度；原有 ±0.5px 容差不变。
- 桌面标题为计数和管理按钮分别留出空间；折叠按钮明确允许 SVG 显示，取消文字省略策略。受控宿主复现了计数重叠，但未复现截图中的原生箭头异常，因此箭头在实际 Obsidian 中的效果仍待确认。
- 左右面板之间新增 8px 命中宽度的拖动分隔线，最小左宽 180px，右侧至少保留 320px。拖动按动画帧合并，宽度进入原有视图会话；窗口变窄时自动约束显示宽度。
- 分隔线支持方向键（10px）、Shift + 方向键（40px）、Home/End、Escape 取消拖动、双击恢复默认。窄窗口纵向布局隐藏分隔线；移动端不创建此控件。

## 验证

Chromium 154 + `tests/host.js` 受控 Obsidian 宿主，沿真实插件代码 `SearchView.onOpen` / `onResize` / 会话恢复 / `onClose` 执行。测试不等于原生 Obsidian 验收。

| 检查 | 结果 |
|---|---|
| 工程静态检查、构建 | 通过；150 模块、644 静态依赖、0 未解析符号 |
| 新增桌面/移动导航回归 | 47/47 通过，含浅/深色、鼠标/键盘、宽度恢复、窄窗约束、销毁清理、文件新增/重命名计数 |
| 搜索条件浏览器验收 | 候选 144/144 通过，无脚本错误 |
| 滚动状态保存及卸载清理 | 桌面、移动模拟均通过 |
| 全量 Node | 251/255 通过；4 个上传代码已有的原型/方法快照差异仍失败 |
| 历史浏览器 A/B 精确对照 | 4 个配置均在初始快照处不匹配；上传候选此前已与该旧基线不同，本次桌面分栏也有预期布局变化，未改写基线或放宽断言 |
| 原生桌面、iOS、Android、外部集成 | 本次未执行实机验收 |

Node 已有失败为 `BatchMetadataService`、`NavigatorCustomization`、`LocalSearchPlugin` 的 prototype contract，以及 v5.2 formal baseline method order/descriptor/name/arity 对照。工程中的两个历史绝对基线路径通过本地只读映射辅助脚本定位到现有 `baseline/`；源码和冻结快照未因此修改。

性能夹具包含 2,400 个文件、200 个文件夹。12 次分组开合时，导航行几何读取由 3,552 次降至 0；同步处理耗时中位数约 8.55ms → 0.30ms。12 次文件夹切换的投影耗时中位数约 12.75ms → 4.30ms，投影内物理目录扫描由 12 次降至 0。此数据仅代表受控环境中相应代码段，不是用户电脑上的整帧延迟或速度保证。原始结果见 `reports/desktop-navigator-before.json` 和 `reports/desktop-navigator-results.json`。

首轮新增回归在旧实现上出现 7 项失败；开发期间发现全局返回手势会抢占分隔线，因此复用已有 resize 手势优先级标记。最终扩展用例中的“重开宽度”曾错误地在纵向布局检查横向宽度，已调整为回到横向布局再验证，保存值本身正确。

## 使用覆盖包

关闭插件，备份现有 `main.js`、`styles.css`，将候选 ZIP 中这两个文件覆盖到已安装 GLS 的原插件目录，再启用插件。保留原 `manifest.json` 和 `data.json`。上传源码没有原始 manifest，因此交付为双文件覆盖包。

桌面左右分栏模式下，将鼠标移到导航与结果之间的竖线，出现左右拖动光标即可调宽；双击竖线恢复默认。测试时重点观察连续切换文件夹、开合分组和目录、箭头方向以及重新打开面板后的宽度。

源码修改集中于 Navigator 控制器、新增 `desktop-pane.js`、结果越界判断与独立 CSS。`dist/` 由构建脚本生成。冻结 `baseline/`、插件身份、用户文件及移动端页面切换规则保持原有实现。
