# GLS v5.2 · Navigator 一体化操作面板 v1（开发候选）

## 唯一研发起点
正式 GLS v5.2「分级标签极速创建 v1」2026-10-19 完整模块化 Source，SHA256 `05cc6ef1c0a8f7dadcfaf19cf0306cf12cf7c58477c08f261d9c9682969ec55f`。正式版保持只读。候选修改 `src/`，打包仍为单 `main.js` 加 `styles.css`；不安装新 manifest、不修改用户 data.json 或元数据目录。

## 交互
- Mobile Navigator 的文件夹、标签、属性键、属性值长按打开统一对象操作面板；桌面沿用 contextmenu 立即打开。
- 已有 Facet Picker 右上角的对应管理动作由原有 `runSidebarMaintenance` owner 执行，不新增属性或标签写入器；文件夹直接包含新建子文件夹、重命名、结果排除、删除，标签包含重命名、删除，属性键包含重命名、固定、显示排除、结果卡显示开关、删除，属性值包含重命名、删除。
- 外观图标、浅深颜色、背景、恢复、上下分割线、导航排序统一留在原 `NavigatorCustomization` owner；对象操作、外观与导航、排列有独立分组线；没有意义的动作不显示。
- 仅对象操作菜单改为内容自适应的高度，移动端最高约 570px，超出时内部滚动。其它 Picker 的高度/焦点/滚动合同均不变。
- 新设置“长按弹出速度”，默认 300ms，范围 180–700ms，20ms 步长，保存于既有设置。移动超过 8px、滚动或指针取消时取消待执行长按；同一手势防止导航误触；iOS 原生 contextmenu 不能抢跑用户设置的阈值。

## 同名重命名规则
- **文件夹**：目标同名文件夹存在时，递归将源树迁入目标树，子目录同名合并；文件撞名沿用 GLS 原 `_availablePath` 生成 `-文件重名` 避让，绝不覆盖目标文件。源目录确认清空才删除空目录，并迁移导航设置。文件移动不是跨文件的事务，宿主途中失败会保留已迁入项、停止继续操作并提示迁入数量，绝不用过时快照回滚用户数据。
- **标签**：源标签树重命名到已存在的目标树时，合并所有子路径，Frontmatter 标签用现有唯一化规则去重，保持既有 Picker 顺序/筛选状态迁移机制。
- **属性键**：已有目标键时，文本/文本列表冲突合并唯一值，不覆盖旧值；数值/布尔/日期等冲突如果无法无损合并，整个操作在预检阶段停止。目录候选值合并，目标已有的筛选池固定/显示设置优先保留，创建元数据中源/目标属性筛选值取并集。目标已设置的数据类型优先保留，不把源类型覆盖到目标。
- **属性值**：沿用正式版原有 `renameVaultPropertyValue`；列表迁入同名值后去重。
- 上述特殊“同名合并”只在本次 Navigator 对象菜单的重命名中打开；其它既有 Picker 的重命名语义仍按原正式路径执行。

## 验收边界
Node 完整回归、Chromium 模拟宿主交互和数据迁移已验证，**没有 iPhone Obsidian/WebKit 真机证据**。用户首次安装仍应保留原有双文件备份，尤其优先验证大量嵌套文件夹迁入、特殊类型属性冲突、长按滚动以及 iOS 面板尺寸。正式版本需另行明确冻结授权。
