# 桌面侧栏点击交互候选 · 2026-10-21

用户在上一候选安装后仍反馈：点击左侧文件夹、展开/折叠卡顿，鼠标按住时有不喜欢的中间底色。本候选继续从 `fix/desktop-sidebar` 的源码修改，未升级正式冻结基线。

本次行为：

- 桌面侧栏的文件夹行按住时保持悬停底色，松开才提交选择；没有第三种按压填色。保留键盘焦点轮廓、原生点击取消和右键操作。
- 展开一个分支时，未变化的兄弟行不再重复设置属性、图标、外观和排序控件。缓存忽略目录节点的惰性子树，并在索引、维护模式、外观和跨窗口设置变化时失效。
- 结果提交后，桌面侧栏导航在同一次绘制前合并刷新，快速连续点击采用最后一次状态，避免定时器分两次显示左右状态。
- 移除树刷新中的重复页面同步和原点滚动布局读取。侧栏发布自身已提交的共享状态时直接确认，其他宿主继续接收；有未合并字段的旧侧栏仍经过原交互门禁。

移动侧栏保留触控按压反馈与原投影时序；其他窗口的 Picker 样式、定位逻辑没有新增调整。继承上一候选的侧栏内弹窗、顶部命令栏、分栏调宽和主搜索右置。

截图中结果上方的「文件夹 00-收集」属于配置的快捷筛选池；当前浏览范围由标题与条件条表示。这次没有将快捷项误改成当前路径，也没有更改筛选数据语义。

## 验证与边界

回归脚本使用实际 `SearchView.onOpen` 与插件控制器，Obsidian API 由测试宿主模拟。鼠标脚本执行按下、保持、松开、连续切换和展开/折叠，包含 161 文件及 2,400 文件两组数据、4 倍 CPU 限速。修复前按住底色改变，展开/折叠会写入无关兄弟行；修复后验证这些行为消失。计时只是云端 Chromium 的诊断数据，不代表用户电脑帧率。

专项还覆盖浅/深色、拖出后松开不选中、键盘展开、卸载前待执行刷新、跨宿主外观失效、惰性子树不被缓存遍历、桌面 Tab Picker 与移动侧栏按压反馈。共享状态测试覆盖正常传播与旧 Picker 的字段合并。

最终结果：新增点击/缓存/宿主专项 26/26、共享状态 2/2、桌面导航 55/55、侧栏弹窗 80/80、移动侧栏 96/96、搜索验收 144/144；Chromium Portal 48/48、Caret 36/36、索引重试 7/7。静态检查与构建通过。完整 Node 253 通过、4 个既有原型合同失败；历史浏览器快照 A/B 仍为 4 个既有失败。WebKit 与原生设备未测。

最终检查结果见 [验证记录](../reports/sidebar-click-validation.json)，交互证据见 [点击记录](../reports/sidebar-click-results.json)。历史 Node 原型合同及旧版浏览器快照存在已知差异，按实际失败记录列出，没有改写冻结基线来使其通过。原生 Obsidian、用户电脑和 iPhone 真机尚未验证。
