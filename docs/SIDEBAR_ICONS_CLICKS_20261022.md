# 侧栏重复箭头与连续筛选修订 · 2026-10-22

从 `c3a54b9` 派生，继承移动文件夹 Picker 光标修复及此前侧栏改进。仍为开发候选，待原生 Obsidian 验收；未晋升冻结基线。

## 修复与范围

复用导航行时，原逻辑直接再次调用宿主 `setIcon`，依赖宿主自动清空旧 SVG。旧测试适配器恰好会清空，因此漏掉了追加式图标适配器中的重复箭头。新增 Navigator 内部 helper，明确移除旧 SVG，再设置一枚新图标；保留 Hover Hint Owner 的隐藏无障碍标签，兼容追加与清空两种行为。覆盖分组箭头、子树箭头、导航图标、命令栏和维护动作，其他 Picker/窗口的图标实现不变。

桌面 sidebar 的结果列表原先会同步构建可见区加前后各一屏的卡片；每次筛选切换都支付这部分屏外成本。现在前后缓冲各半屏，继续使用原虚拟列表 Owner，并始终覆盖实际可见跨度；移动端及其他宿主沿用原预算。没有增加点击防抖或忽略重复点击，原有选中／取消语义保留。没有修改 CSS、弹窗坐标、数据、设置默认值或公开方法。

## 复现与验证

新增 `sidebar_repeat_click_audit.py` 使用追加式图标适配器，模拟真实 SearchView 生命周期。161 / 2400 文件各连续执行 40 次分组开合、20 次重复选择、30 次切换，无人为加入 120–160ms 点击间隔。修复前两组均复现重复 SVG；修复后 180 次点击全部送达，高亮与筛选结果一致，箭头始终一枚。另验证无障碍标签节点保留、滚轮连续移动与键盘跳到最后结果；共 16 项通过。

新增窗口预算 Node 测试 2 项通过，涵盖其他宿主、少量结果、超高视口和实际可见跨度。新增前后性能脚本使用单独构建的父候选，与新版本按 A/B、B/A 顺序运行；没有并行跑其他浏览器测试。
