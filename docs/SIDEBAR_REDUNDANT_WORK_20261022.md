# 侧栏冗余动作审计 · 2026-10-22

本轮在固定标签/属性列表候选上继续审计，消除两类已复现的重复工作。仅修改 `src/features/navigator/SearchNavigatorController.js`，仍为待原生 Obsidian 验收的开发候选。

## 发现与修复

1. **列表结构未变，仍逐行测量位置并恢复滚动锚点。** 侧栏滚动后，选择文件夹、切换标签和查询刷新都走全量位置测量。现在以实际投影使用的同一结构签名检查文件夹树、标签树、属性列表、分组可见性及当前索引/偏好版本。结构未变时直接更新数字/选择，保留浏览器当前滚动位置；展开折叠、索引/偏好更新、排序/维护及显式会话恢复仍走原有锚点路径。
2. **目录范围未变，仍重新扫描导航候选和计数。** 导航候选只受文件夹与全局排除影响，精筛/查询变化不需要重算它。现在只缓存当前文件夹集合对应的导航候选、分级标签计数、属性存在计数；切换范围即替换，索引、文件事件、偏好更新会清空，销毁时释放。没有积累每个访问过的目录，没有新增权威索引。

搜索与结果筛选仍执行。专项验证中每次选择只调用一次 `performSearch`；展开分支不启动搜索。重复点击已选目录/标签具有既有的取消筛选语义，不能当成无效点击丢弃。没有通过防抖、吞点击或延迟刷新来掩盖卡顿。

上一轮的固定标签/属性库存、零计数项、工具栏与右侧搜索位置保留。移动端和其他宿主的候选/锚点路径未启用本次优化；弹窗位置、焦点、手势、CSS、manifest 和 data 未修改。
