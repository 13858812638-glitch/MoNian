# 整体侧栏刷新优化候选 · 2026-10-21

从 `6676d32` 的桌面侧栏候选继续开发，响应用户对整个侧边栏继续优化的要求；未升级正式冻结基线。

## 改动与检查范围

- 顶部命令栏只写入发生变化的可见状态、按钮状态和文本。一次刷新只规范化一次工具栏配置；动态快捷项、排序状态、折叠提示仍使用原 Owner。
- 不变的分组标题复用已有外观与排序控件，配置、图标、分组状态变化时重新装饰。计数更新可见文本节点，保留共享 Hover Hint Owner 创建的无障碍标签。
- 桌面侧栏不再反复写回被 Hover Hint Owner 转换的 `aria-label` / `title`。仅缓存导航自身的标签意图；`aria-pressed` / `aria-expanded` 等动态状态仍检查实时 DOM。移动端保持原写入路径。
- 侧栏菜单只响应会移动宿主、当前锚点或父菜单锚点的滚动。滚动右侧结果时，左侧菜单无需重新定位；若菜单本身从结果行打开，则继续跟随结果滚动。嵌套菜单和宿主祖先滚动均覆盖。
- 侧栏内居中对话框只跟随宿主位置变化，内部列表滚动不再反复测量宿主。其他宿主的定位订阅不变。

整栏回归还覆盖搜索、结果虚拟列表、连续目录切换、展开/折叠、滚动位置、快捷命令、键盘排序、分栏拖动及弹窗关闭/卸载。结果虚拟窗口和按帧合并的分栏拖动继续由现有控制器负责。本轮不修改 CSS、持久化结构、插件标识或正式基线。
