## 已实现

1. Navigator 上下文操作 Picker 恢复共享的固定高度框架；去掉旧候选的 auto 高度强制覆写，内部动作列表滚动。
2. 根目录增加“新建文件夹”，普通文件夹增加“新建子文件夹”；调用原生 `openFolderCreateDialog` 与文件操作服务。
3. 标签增加“新建同级标签 / 新建子标签”，进入现有分级标签 Picker 并带入父级路径。标签必须附着实际文件：使用已选择文件，若无选择则使用活动文件；没有可写文件时明确提示，不造第二套虚拟标签台账。
4. 属性键菜单增加“新建属性值”；调用既有 `addPropertyCatalogValues`，保存纯目录候选值，不修改未选定的文件。
5. 删除侧栏工具的独立全局“拖拽排序”入口；从当前对象菜单打开 `group/folder/tag/property-key/property-value` 的局部拖拽。复用唯一 `PointerSortCoordinator`；排序控制手柄仅对当前类别显示。
6. 文件夹跨父级调用真实文件夹 `moveFolderTreeNode`；标签拖拽调用真实 Vault 标签前缀迁移服务；不允许拖到自身/后代。原同级排序逻辑不变。
7. 属性键→属性值始终是唯一两级结构。属性值拖放到**另一个属性键**时，使用新的 `moveVaultPropertyValueToKey`。在受 GLS 管理且未被排除的文件内全面预检：只接受文本/列表两类实际字符串；源列表保留其余值；目标文本已有不同值则整个操作拒绝；目标列表追加时保留原次序和内容、不重复追加已有值；数字/布尔/日期/复杂值全部拒绝。
8. 跨键写入通过现有 Markdown Frontmatter/非 Markdown 附属元数据写入服务执行，更新索引、现有目录候选值与排序；不额外创建自有数据源。
9. 桌面常规属性键点击仍打开 Picker；仅显式使用“移动该键的属性值”时展示临时二级可拖拽值，退出后恢复原界面。移动端保留原有属性展开。
10. 重命名前，在共享 Picker 关闭 **之前** 保存 Navigator 滚动位置；重绘时恢复，取消/未修改时清理快照，防止下次操作使用过期位置。现有展开路径回映射逻辑保留。

## 安全边界

- 跨键属性迁移遵循 GLS 现有 `metadataFiles()` 的 `isPathExcluded` 范围；显式排除的文件不自动写入，保持原系统权限 / 排除语义。不是“包括用户排除目录在内的全盘强制改写”。
- 多文件预检在第一笔写入前完成；成功预检不等同于跨文件原子事务。若发生并发编辑、磁盘或宿主写入失败，先前已成功的单文件可能不会回滚，原错误处理会明确列出失败。绝不静默覆盖目标冲突。
- 标签创建使用现有批量文件 Picker，因此无当前文件且未选中文件时不能生成实际标签；这是 Obsidian 标签的文件附着约束。
- 本次没有迁移历史数据，也没有修改用户笔记、设置数据或原正式冻结资产。
