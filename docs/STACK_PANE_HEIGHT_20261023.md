# 自适应上下分栏高度 · 2026-10-23

以本会话上轮交付提交 `aed6f38` 为唯一开发基线。截图中的窄桌面侧栏进入 `stack` 布局后不能调高，根因是现有 divider 的 JS 与 CSS 均只支持 `split`：上下布局隐藏分隔条，指针只读 clientX，导航滚动区有固定高度及 45% 外框上限。

## 实现

- 复用 `createDesktopNavigatorPane` 的单一分隔条和拖动生命周期。按当前布局选择轴：左右调整 width/clientX，上下调整 height/clientY；开始、动画帧合并、提交、取消与清理共用实现。
- 尺寸限制、命中区、光标和外框都由 CSS 定义，JS 只读取约束并写入用户拖出的运行时尺寸。去掉 JS 中原 180/320px 几何默认值，宽度下限改为 CSS Token；没有新增 Style Settings 参数或 CSS Snippet。
- 上下布局让导航滚动容器填满面板。一般高度至少保留 120px 导航、160px 结果空间；极短窗口由导航最小高度限制为一半保证两区不越界。默认树滚动区沿用 180px 基准，双击恢复默认。
- Navigator 仍是尺寸 Owner。可选 `paneHeight` 与既有 `paneWidth` 一并进入原会话捕获/恢复路径；切换布局互不覆盖尺寸，无新增插件设置或第二份数据源。旧会话没有高度时自然使用默认值。
- 分隔条随布局更新无障碍方向、名称和实际读数。上下方向键调高，左右方向键调宽；Shift 加大步长，Home/End 到边界，Escape/失去捕获/指针取消/窗口失焦恢复拖前值。
- 桌面宿主仅改变高度时只同步分隔条，活动拖动取消过期边界；不调用搜索或导航投影。移动端继续由原宿主处理，不挂载桌面分隔条，不增加键盘补偿。

拖动开始读取几何边界，pointermove 只记录坐标并合并到同一个 requestAnimationFrame；每帧消费开始时的边界，结束后才同步实际读数和原会话通知。

## 复现与验证

改动前，亮/暗主题均复现上下布局分隔条不可见。首版专项发现 flex-shrink 会让结果内容把用户设定高度压回下限；修正为固定 flex-basis 后再次检查，保留初版失败记录，未放宽拖动位移断言。

新专项通过真实 SearchView 打开/缩放/关闭链验证：拖动实际位移与内部滚动区同步、键盘、双击、Escape、失焦/指针取消、拖动中切换布局、RTL 纵向坐标、宽高独立保留、结果最小空间、仅高度变化零搜索/零导航投影、短窗口边界、关闭重开恢复与销毁清理。既有桌面专项中“上下布局隐藏分隔条”的旧断言根据本次需求改为“可见且为水平分隔条”，其他断言保留。

新增专项 45/45，通过的当前行为检查合计 1247 项；工程检查及可复现构建通过。

回归还包含左右拖宽、搜索输入保留、移动导航、Picker、焦点、连续筛选、属性展开及现有交互合同。工程检查、构建、Node、历史浏览器 A/B 和当前行为测试的实际结果见 [验证报告](../reports/stack-pane-validation.json)。冻结基准未改动；既有 Node 4 项原型差异与历史 A/B 4 组初始快照差异仍单独记录。

这是受控 Chromium 宿主回归，未实际运行原生 Obsidian 或 iOS/Android/WebKit。没有根据模拟结果承诺全部实机行为一致。

## 安装

`GLS-Stack-Resize-20261023.zip` 仅含本轮构建的 `main.js` 和 `styles.css`。覆盖现有插件目录的同名文件后重载插件，保留 `manifest.json`、`data.json`。将鼠标移到上方导航与下方搜索框之间的分隔线，出现上下调整光标后拖动即可。公网下载与逐字节校验见 [交付记录](../reports/stack-pane-delivery.json)。
