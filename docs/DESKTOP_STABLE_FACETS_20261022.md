# 桌面侧栏固定标签与属性列表 · 2026-10-22

切换文件夹时，桌面 sidebar 保留全库导航范围内的标签树和属性键列表，只更新当前目录范围的计数与选中状态。无关项显示 0，仍可点击；行的位置不会因切换目录而跳动。此版本是开发候选，等待用户原生 Obsidian 验收，未修改正式冻结基线。

## 行为与范围

- 列表来自现有 `_navigationCandidates().all`；右侧计数来自 `.scope`。全局文件夹排除和属性键排除仍有效，查询词、其他精筛不缩减导航目录。
- 分级标签按文件去重计数；空字符串、false、0 仍是“存在该属性”。属性组总数按至少具有一个可见属性的文件去重。
- 当前目录没有匹配的标签/属性仍显示 0。点击标签仍执行原筛选；属性行仍打开现有共享 Picker，其值与候选范围保留原语义。
- 原有树展开状态、自定义排序、分隔线与“显示全部”入口保留。内嵌树仍有原来的 70 项、属性键 40 项渲染上限；本次不取消这些保护。
- 移动端和其他窗口宿主仍使用原目录相关列表。弹窗定位、光标、手势、CSS、设置结构、manifest 和 data 均未修改。

## 实现

唯一运行源码变更：`src/features/navigator/SearchNavigatorController.js`。

标签树和属性键派生模型跨搜索结果批次复用；文件创建、删除、重命名、索引变化、偏好变化会使缓存失效。它们只缓存现有索引的显示模型，没有第二套权威索引。关闭时释放缓存。

普通桌面侧栏结构未变化时直接更新已有行的计数和选中属性，跳过排序、描述符构建、装饰和行插入。计数文本只在变化时写入，保留 Hover Hint 管理的辅助标签。属性存在计数在当前文件夹范围一次扫描完成，不为每个属性整理未显示的值列表。维护和排序模式继续走完整投影。

|---|---:|---:|
| 标签/属性行 DOM 添加和移除次数 | 123 | 0 |
| 导航行重复装饰次数 | 56 | 0 |
| 标签树/属性键模型重建次数 | 26 | 0 |

这是受控夹具中的工作量，不是原生 Obsidian 帧率或耗时承诺。验证覆盖零计数选择、空目录、目录切换、折叠后计数、分级标签去重、空/false/0 属性、属性目录新增、索引增加/修改/删除、排除设置与移动端原行为。

完整门禁结果见 `../reports/sidebar-stable-validation.json`。原有 Node 冻结原型差异及浏览器冻结快照差异仍记录为失败，没有修改断言或更新参考基线来消除失败。首轮新增缓存清理使六个不调用构造器的生命周期夹具失败，已补齐部分初始化状态下的安全清理，并重新运行相关检查。

原生 Obsidian 桌面、原生 iOS/Android、WebKit 与真实第三方集成未验证。
