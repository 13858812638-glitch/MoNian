# 桌面侧栏与搜索条右置候选

下载 `GLS-Desktop-Search-Right.zip`（在 GitHub 文件页点击 Download raw file）。

关闭插件，备份并替换原插件目录里的 `main.js`、`styles.css`，保留原 `manifest.json`、`data.json` 后重新启用。
